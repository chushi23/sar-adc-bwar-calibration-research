# LIMITATIONS — BWAR Implementation Refinement 轮

1. **行为级口径不变**：沿用 p4_8 引擎与全部约定（含"非单调即 Inf 失败哨兵"的严格口径）。本轮全部结论
   对该口径敏感——特别是 CAL2 微反转问题本质上是口径-边界效应，换合并码区解码器即消失（见 final_report 判决）。
2. **搜索非全局最优**：粗网格 4125 + 细网格 765 + topR 定向探针 {24..72}；地形陡峭（相邻配置可差 40 个百分点），
   不排除存在更优解。lowR1 细网格仅在 256±32、topR 仅在 20±4 + 探针点采样。
3. **CAL2 模型**：测量噪声为每位权独立白高斯 + 共模系统性偏置两种；未建模 1/f 漂移、温漂、测量电路自身的
   非理想。Navg 上限 512。σ_cal≈1e-4 LSB 量级的行为靠外推，未直接仿真。
4. **编码评估**：ERROR-ONLY 量程 ±256 LSB 取自首颗芯片 |dW|max≈11 LSB 的保守放大；saturation=0 说明量程
   富余，可再收窄省位。分数位/饱和策略未做位级实现。
5. **Phase C**：残余 offset 为均匀常数模型（每判决同值）；与权重校准的联合仅在一个操作点 (0.05, 64)。
6. **PDK σ 案例**：σ=1.67487% 引自 phase03 LIMITATIONS #8（300-run MOM MC），未重跑原始 Spectre MC；
   未找到独立的 150 fF PDK sigma 文件即不猜的原则下，这是唯一有出处的实测值。
7. **判决的口径依赖**：CONDITIONAL GO 的唯一先决项（CAL2 解码器约定）是口径问题而非电容网络问题；
   若维持严格口径且不接受合并解码器，则应视为 NO-GO-for-CAL2-spec（CDAC 本体仍 GO）。
8. **未做**：合并码区解码器的行为级实现与验证（下一轮第一件事）、开关阵列寄生模型、逐位开关能量、
   桥 Cb=2 Cu 的版图共质心方案、Virtuoso/Spectre/版图（任务书明令禁止）。
