SAR ADC 电容失配校准研究 · 学习路径与程序调用路径

三阶段 MATLAB 工程（calibration_architecture_study → calibration_architecture_study_p4_8 → bwar_implementation_refinement）的统一阅读导航。本文档与已加中文注释的源码配套使用。

阅读前提：本工程研究的是 16-bit SAR ADC 的电容 DAC（CDAC） 在电容随机失配（σu≈1.63%，面积律 σ(w)=σu·√cap）下，能否靠前台数字校准达到 16-bit 规格（DNL<1、INL<4、零缺码、单调）。四个基础架构为 Split / Current / BWA / BWAR，校准分 CAL0（无校准）/ CAL1（理想权重）/ CAL2（带噪+量化+编码）三档。

一、三个项目的关系与定位

最重要的纪律：后一阶段通过 addpath 只读复用前一阶段的引擎函数（network_weights、adc_metrics、quantile_linear 等），零改动。因此真正"重写/新增"的只是架构定义、冗余变体与顶层编排；理解前两个阶段，第三阶段就水到渠成。

五、关键概念速记

CDAC 有效权重
每个电容的"权重"= 自身容值 × 所处节点电压。桥电容引入非对角耦合，权重不是简单的二进制 2k，必须用节点方程整体求解。
面积律失配
σ(w) = σu·√cap，σu=√(K/Cu)≈1.63%。电容越大相对失配越小；这是全工程随机性的来源。
精确判决树 transfer_tree
用区间传播而非逐点扫描：把输入区间沿 SAR 判决二叉细分，塌缩到空/零的区间即"缺码"。比扫 216 点快得多。
两种判决约定
fullstep（Current 架构用）与 monotonic（BWA/BWAR 用）。冗余码只能加在 monotonic 约定下才保持单调。
三级校准 CAL0/1/2
CAL0=名义权重（无校准）；CAL1=oracle 真实权重（架构可达性上界）；CAL2=带噪声+量化+编码（现实可实现）。
前端数字校准平均律
多次平均使有效噪声 σ/√Navg，是 CAL2 能在有限字长下达标的关键。
